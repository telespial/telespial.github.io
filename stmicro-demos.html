Smart Pong

The project compares touch-driven HUMAN control, a fixed classic ALGO predictor, and an adaptive EdgeAI predictor with runtime learning and telemetry. Its `AI/ALGO`, `ALGO/AI`, and `2AI` modes make the control paths directly comparable.

Open the Smart Pong README and setup. The child README and `start_here.md` are authoritative for the STM32H7S78-DK toolchain and run sequence.

See EIL for bounded runtime context and EmbeddedX for the wider specification family.
