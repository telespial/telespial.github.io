Embedded Intelligence Layer

EIL describes how EdgeAI behavior can sit alongside firmware without taking over deterministic application control.

Documented boundaries

The specification covers inference request patterns, advisory and anomaly outputs, explainability, integration APIs, runtime safety expectations, and hybrid or adaptive behavior boundaries. The application remains responsible for final control decisions.
