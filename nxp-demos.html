NXP EdgeAI Demos

This catalog contains practical demonstrations for the NXP FRDM-MCXN947 platform. Each child project keeps its own setup, status, and limitations as the authoritative record.

Examples

  • 3D printer spool size ToF uses a TMF8828 8×8 ToF sensor and documents FULL, MEDIUM, LOW, and EMPTY display states.
  • EV charger anomaly documents a 20 Hz replay-oriented anomaly demonstration with explicit non-production safety scope.
  • Package transport records adaptive anomaly scores, warning/fault transitions, reason codes, and replay evidence.
  • Smart Pong compares human, fixed algorithm, and adaptive EdgeAI control modes on the same display system.
  • CGM insulin pump is a research/demo platform and is not clinical software.
  • Sphere combines FRDM-MCXN947, LCD-PAR-S035, and FXLS8974CF accelerometer input in a graphics sandbox.

Setup and boundaries

Start with the selected child README and `STATUS.md`; build and board prerequisites differ by project. These demonstrations are not interchangeable firmware packages and no automatic flashing is implied.

Browse the source repository · See MRD for structured hardware facts and EIL for bounded runtime integration.
