Machine Readable Datasheets

A Machine Readable Datasheet (MRD) represents firmware-relevant hardware information in structured data that software tools and AI coding systems can consume.

What it captures

The specification covers device identity and revisions, packages and pins, pin multiplexing, registers and fields, peripheral blocks, clocks, resets, interrupts, DMA, interfaces, constraints, conflicts, errata, and source traceability. The repository includes a schema configuration and an example MRD document.

Practical use

An MRD can provide the hardware facts needed before selecting pins, configuring a peripheral, or checking a model target. It does not replace a vendor datasheet or prove that a board is wired a particular way; board connectivity belongs in the related connectivity specification.
