EmbeddedX

EmbeddedX is a family of specifications and workspace conventions for structured embedded development. It organizes hardware facts, board connectivity, model metadata, runtime boundaries, coding controls, and deployable packages before tools touch firmware.

Practical entry points

  • Project framework defines workspace structure and required project inputs.
  • Rules and control documents modification and review boundaries.
  • Project manifest example shows the structured project entry point.
  • Public EmbeddedX specification source indexes the specification family.

Use MRD for firmware-visible hardware data, EIL for bounded runtime intelligence, and Baby Model Zoo for small model projects.
